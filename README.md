# KADR — приложение для Android

Нативное приложение на Java для Android 10 и новее. В каждой серии находит **несколько отдельных фрагментов** и сохраняет каждый выбранный момент отдельным видео со звуком. Интернет, регистрация и сервер для работы приложения не нужны.

## Скачать и установить APK

1. Откройте [GitHub Actions → Build Android APK](https://github.com/din820553-debug/KADR/actions/workflows/android.yml).
2. Выберите последнюю успешную сборку с зелёной галочкой.
3. Внизу страницы, в **Artifacts**, скачайте **KADR-Android-APK** (для скачивания артефактов нужен вход в GitHub).
4. Распакуйте ZIP, откройте `app-debug.apk` на телефоне и разрешите установку из этого источника, если Android попросит.

APK появляется только после успешной сборки. Это отладочная сборка, подписанная временным ключом CI. Для последующих отладочных сборок может потребоваться удаление предыдущей установки; это удаляет библиотеку приложения. Исходные видео и экспортированные клипы в галерее сохраняются. Стабильный ключ для релизов Google Play пока не настроен.

## Как пользоваться

1. Нажмите **Добавить видео / серии**. Можно выбрать один фильм или несколько эпизодов.
2. Задайте максимум моментов **на каждую серию**: 3, 5, 8 или 10. Длина каждого фрагмента — 15, 30, 45 или 60 секунд.
3. Запустите поиск в одной серии либо **во всех сериях**. Результаты сохраняются отдельно для каждого эпизода.
4. Просмотрите найденные моменты, поправьте начало и конец, переименуйте, снимите отметки с ненужных.
5. Нажмите **Сохранить выбранные**. Каждый фрагмент появится отдельным MP4 в галерее, папка **Movies/KADR**. Файлами можно поделиться из приложения.

Можно добавить и обрезать фрагменты вручную. Повторный поиск предупреждает о замене правок. При отмене сохраняются уже обработанные серии или уже экспортированные файлы; незавершённый экспорт удаляется.

## Как выбираются моменты

Приложение декодирует до 900 уменьшенных кадров, оценивает движение и смену изображения, исключает почти чёрные кадры и выбирает наиболее выраженные непересекающиеся окна. Для спокойных сцен приоритет обратный. Количество в настройках — максимум: короткая серия или небольшое число подходящих кадров дают меньше результатов.

Это эвристический отбор по изображению, **без смыслового ИИ**: распознавание сюжета, диалогов, шуток и эмоций не реализовано. Оцените результаты перед публикацией. Опенинги и титры автоматически не распознаются; границы можно исправить вручную.

## Видео и экспорт

- Наиболее совместимы локальные **MP4, H.264 + AAC**. Поддержка других контейнеров и кодеков зависит от Android и устройства. Защищённые DRM-файлы не поддерживаются.
- Экспорт через Android MediaExtractor / MediaMuxer копирует исходные видео- и аудиодорожки без перекодирования. Разрешение, пропорции и качество сохраняются; 9:16, фильтры и субтитры в этой версии не добавлены.
- Начало выравнивается к предыдущему ключевому кадру. Поэтому в экспортированном файле может быть несколько дополнительных секунд перед выбранной границей.
- Для тяжёлого анализа держите приложение открытым. Работа не перенесена в фоновую службу; при завершении процесса Android незавершённая операция прервётся. Для больших серий нужны свободное место и время на декодирование.
- Исходники не копируются и не отправляются на сервер. Приложение хранит URI-доступ, метаданные и границы моментов в своём хранилище, миниатюры — в кэше. После перемещения исходника или отзыва разрешений добавьте серию заново. Миниатюры могут исчезнуть при очистке кэша; само видео и границы остаются доступны, пока действителен URI.

## Сборка и проверки

Откройте проект в Android Studio, установите SDK 35, используйте JDK 17 и Gradle 8.11.1. Gradle Wrapper в репозитории не приложен; CI устанавливает указанную версию через `gradle/actions/setup-gradle`.

```sh
gradle :app:testDebugUnitTest :app:assembleDebug
```

GitHub Actions собирает установочный debug APK и запускает unit-тесты селектора: несколько моментов из одной серии, отсутствие пересечений, короткое видео, приоритет спокойных кадров, ограничения количества и выбор 10 фрагментов. Проверка на физическом Android-устройстве нужна отдельно.

Используйте видео, на которое у вас есть права.
